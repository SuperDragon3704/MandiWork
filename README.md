# Hanzi Steps

Static site, no build step. Deploy the repo root with GitHub Pages.

- `index.html` page shell
- `css/style.css` styles
- `js/store.js` saved progress (localStorage)
- `js/data.js` levels, menu, word-list loader
- `js/core.js` helpers and the Anki-style scheduler
- `js/views.js` menu, tests hub, vocab views
- `js/tests.js` practice tests and full-length exams
- `js/learning.js` path lessons and the shared reader
- `js/adaptive.js` adaptive review
- `js/remote.js` Wikibooks textbook and daily reading feed
- `js/qotd.js` question of the day and calendar
- `js/app.js` router, events, theme, background

Sources: Complete HSK Vocabulary (MIT), CC-CEDICT (CC BY-SA 4.0), Wikibooks and Chinese Wikipedia (CC BY-SA).
